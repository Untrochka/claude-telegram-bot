# Учёба: от сильного middle к senior и дальше

## Честная оценка (сентябрь 2026, нужно подтвердить тестом)
Сильный middle по доставке результата: React, Next.js, TS, FSD, свой VPS, деплой, реальные клиенты.
Вероятные дыры:
- основы JS и браузера: event loop, замыкания, как браузер рисует страницу, почему тормозит;
- тесты и производительность;
- сеть и бэк: HTTP изнутри, базы данных, SQL, авторизация;
- руки слабеют: код клиентам пишет ИИ, Азиз проверяет. Senior должен уметь написать сам, чтобы видеть, где ИИ ошибся.

## Правило
Программирование сейчас — навык для денег. Значит учим то, за что платят клиенты Untra, и учимся на их же проектах.
15 минут в день, одна тема, первые 15 минут в коворкинге (~10:30). Пример пишется сам, без ИИ.

## Этапы (решено 02.10.2026)
| Когда | Что | Зачем для денег |
|---|---|---|
| **Октябрь–январь** | Не «повторять фронт», а закрыть дыры на своих же проектах: раз в день понять и переписать сам один кусок кода, который написал ИИ (event loop, промисы, TS, рендер, производительность — по мере встречи) | Сам вижу, где ИИ ошибся. Меньше багов клиентам, быстрее сдача |
| **Февраль–май** | Бэк на своём стеке: Postgres, SQL, авторизация, API в Next.js | Интернет-магазин от 12 млн и web apps для EN-клиентов требуют бэка. Это самые дорогие услуги в прайсе |
| **Потом (университет или когда нужен бэк-работодатель)** | Go | Понятия (HTTP, SQL, авторизация) уже будут знакомы, Go останется только синтаксисом и инструментами |
| Раз в неделю | ИИ: токены, контекст, RAG — на примере своего бота | Бот = живой проект для практики |

ML: не убежище от ИИ, там конкуренция ещё жёстче. Всерьёз — позже, когда в университете будут линейная алгебра и теория вероятностей.

## Этот бот — untra_claude_manager
Его написал сам Азиз (с помощью Claude Code). Node.js, работает на его сервере в Docker через Coolify, модели Claude вызываются через его подписку.
Части бота:
- **Автоответчик** в Telegram Business: читает сообщения клиентов в личке Азиза, присылает ему черновик ответа с кнопками ✅/🗑; часть типовых ответов (отказ, «подумаю», цена, примеры) может отправлять сам. Личные чаты и «ок/хоп» пропускает.
- **Рафаэль** — личный менеджер Мастера в чате с ботом (ты, если ты Рафаэль).
- **/day** — разбор дня: интервью → готовые посты для Untra.dev и vlog.
- Задачи и напоминания: /todo, /remind. Чаты: /chats, /chat. Автоответы: /auto. Память: /remember, /memory. Сброс разговора: /new. Выход из /day: /stop. Список всего: /help.
- Понимает голосовые (расшифровка через Groq Whisper), фото, видео (несколько кадров + звук).
- **MTProto** (если настроен TG_SESSION): бот работает и от аккаунта Мастера — Рафаэль может прочитать ЛЮБОЙ его чат, группу или канал через [[CHAT: …]], без экспорта. Без MTProto — только чаты после подключения Business и загруженные экспорты (result.json).
- **Агент продвижения**: знает стратегии Мастера по площадкам (/strategy; правки — через Рафаэля), напоминает про посты и комментарии в Telegram, Contra, LinkedIn, Reddit по расписанию (/plan), готовит английские версии постов для Contra и LinkedIn, сам ищет Telegram-каналы для комментариев — русскоязычные СНГ и англоязычные, узбекские не берёт (Рафаэль может сам запустить поиск и другие команды через [[ACTION: …]] — см. системный промпт) и присылает черновики комментариев на ✅ (/comments), находит вопросы на Reddit (/reddit). Ничего от имени Мастера не отправляется без его кнопки.
- Черновики (ответы клиентам, посты, комментарии, Reddit) Мастер правит кнопкой ✏️, ответом (reply) на карточку или словами Рафаэлю — Рафаэль видит последние черновики и может попросить бота переписать их. Постоянные правила (как отвечать клиентам, как общаться Рафаэлю, стратегии) Мастер задаёт словами — Рафаэль предлагает сохранить их кнопкой, код менять не нужно.
- Модель везде Opus 5.5. Командой /model меняется только effort по ролям (low по умолчанию, дальше medium, high, xhigh, max).
