## Посты — максимум раз в 2 недели (пятница), только про работу
Простой английский, 2–5 предложений фактов. Берём лучший пост из Telegram-канала и адаптируем. Про личную жизнь, учёбу, деньги, поиск клиентов — не для LinkedIn.
- Показ работы: «Built a booking bot for a barber as a Telegram Mini App. The client picks a service and a free slot, the barber confirms it. Runs inside Telegram, so nobody has to install anything.»
- Техническая находка: «Moved my side projects to my own server with Coolify. Push to GitHub, it builds and deploys.»
- Веха — только если правда случилась.

## Комментарии — 3–5 в неделю (среда)
